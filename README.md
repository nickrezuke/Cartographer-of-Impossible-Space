## 🚀 How to Run Locally
1. Ensure you have the **Git LFS extension** installed (`git lfs install`).
2. Clone the repository: `git clone https://github.com/nickrezuke/Cartographer-of-Impossible-Space.git`
3. Open the folder via **Unity Hub** to automatically generate local solution files.
